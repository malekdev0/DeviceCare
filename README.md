# DeviceCare
Android device diagnostics and maintenance application inspired by desktop system-maintenance tools.

Technology used:
- Kotlin
- Jetpack Compose
- Material 3
- Kotlin Coroutines & StateFlow
- MVVM architecture
- Repository Pattern
- Jetpack Navigation
- Android SDK & System APIs
- Hardware APIs — Camera, Battery, Sensors, Vibration
- File System & Storage APIs
- Network Diagnostics / Socket Programming
- Android Permissions & Security APIs
